— Pipelines de Ejecución —

Pipeline de Render

Traza completa de llamadas para spec2viz render: CLI → Facade → load() → validate() → compile_ir() → render() → write_text().

sequencetype:sequence
      %% spec2viz: generated from docs/architecture/spec2viz/sequence-render-pipeline.yml; do not edit, run `spec2viz diagram validate docs/architecture/spec2viz/sequence-render-pipeline.yml` and re-render
      sequenceDiagram
          actor User
          participant CLI
          participant Facade
          participant Loader
          participant Validator
          participant Compiler
          participant Renderer
          participant Disk
          User->>CLI: spec2viz render spec.yml --backend mermaid
          CLI->>Facade: render_to_file(path, out, renderer)
          Facade->>Loader: load(path)
          Loader->>Loader: yaml.safe_load() + TypeAdapter.validate_python()
          Loader->>Facade: returns BaseDiagram
          Facade->>Validator: validate(diagram)
          Validator->>Facade: returns None or raises ValidationError
          Facade->>Compiler: compile_ir(diagram)
          Compiler->>Facade: returns DiagramIR
          Facade->>Renderer: render(ir, mermaid)
          Renderer->>Facade: returns string
          Facade->>Disk: output_path.write_text(result)
          Facade->>CLI: returns output_path
          CLI->>User: Rendered spec.yml -#gt; output.mmd

Ciclo de un diagram sync

Estados de `spec2viz diagram sync`: el trabajo contra el store es un estado compuesto (validar, escribir, indexar) y un fallo sale de él. Piloto de la notación statechart con nest.

statetype:state
      %% spec2viz: generated from docs/architecture/spec2viz/state-diagram-sync-lifecycle.yml; do not edit, run `spec2viz diagram validate docs/architecture/spec2viz/state-diagram-sync-lifecycle.yml` and re-render
      stateDiagram-v2
          state "Idle" as idle
          state "Syncing against the store" as syncing {
              state "Validating the spec" as validating
              state "Writing documents" as writing
              state "Rebuilding the edge index" as indexing
          }
          state "Synced" as synced
          state "Failed" as failed
          [*] --> idle
          idle --> validating : diagram sync #lt;spec#gt;
          validating --> writing : load() ok
          validating --> failed : load() raises [spec invalid]
          writing --> indexing : documents upserted
          indexing --> synced : check_edges [no errors]
          indexing --> failed : check_edges [--strict and errors]
          synced --> idle : next spec
          failed --> idle : fix the spec

— Flujos de Actividad —

Manejo de Errores en Render

Flujo de decisiones del CLI render: para cada path, intenta load → validate → compile → render, con catch de excepciones por etapa.

activitytype:activity
      %% spec2viz: generated from docs/architecture/spec2viz/activity-render-error-handling.yml; do not edit, run `spec2viz diagram validate docs/architecture/spec2viz/activity-render-error-handling.yml` and re-render
      flowchart TD
          __start([Start])
          receive_paths["Receive SPEC paths from CLI args"]
          iterate_path{"For each path"}
          try_render["Call render_to_file(path, out, renderer)"]
          load_step{"load(path): YAML parse + Pydantic validate"}
          validate_step{"validate(diagram): check cross-references"}
          compile_step{"compile_ir(diagram): pattern-match compiler"}
          render_step{"render(ir, renderer): dispatch to backend"}
          write_output["Write result to disk"]
          echo_success["echo 'Rendered X -#gt; Y'"]
          catch_error["echo error to stderr + sys.exit(1)"]
          done["Exit"]
          __end([End])
          __start --> receive_paths
          receive_paths --> iterate_path
          iterate_path -->|"has_next"| try_render
          iterate_path -->|"empty"| __end
          try_render --> load_step
          load_step -->|"ok"| validate_step
          load_step -->|"ParseError"| catch_error
          validate_step -->|"ok"| compile_step
          validate_step -->|"ValidationError"| catch_error
          compile_step -->|"ok"| render_step
          compile_step -->|"CompileError"| catch_error
          render_step -->|"ok"| write_output
          render_step -->|"RenderError"| catch_error
          write_output --> echo_success
          echo_success --> iterate_path
          catch_error --> __end

— Pipelines de Ejecución —

Pipeline de Render

Traza completa de llamadas para spec2viz render: CLI → Facade → load() → validate() → compile_ir() → render() → write_text().

sequencetype:sequence
      sequenceDiagram
          actor User
          participant CLI
          participant Facade
          participant Loader
          participant Validator
          participant Compiler
          participant Renderer
          participant Disk
          User->>CLI: spec2viz render spec.yml --backend mermaid
          CLI->>Facade: render_to_file(path, out, renderer)
          Facade->>Loader: load(path)
          Loader->>Loader: yaml.safe_load() + TypeAdapter.validate_python()
          Loader->>Facade: returns BaseDiagram
          Facade->>Validator: validate(diagram)
          Validator->>Facade: returns None or raises ValidationError
          Facade->>Compiler: compile_ir(diagram)
          Compiler->>Facade: returns DiagramIR
          Facade->>Renderer: render(ir, mermaid)
          Renderer->>Facade: returns string
          Facade->>Disk: output_path.write_text(result)
          Facade->>CLI: returns output_path
          CLI->>User: Rendered spec.yml -#gt; output.mmd

Pipeline de Build Deskops

Traza completa para spec2viz build: CLI → Deskops → parse_atoms() → render_deskops() → write_text().

sequencetype:sequence
      sequenceDiagram
          actor User
          participant CLI
          participant Deskops
          participant AtomParser
          participant AtomsDir
          participant VistasYML
          participant Template
          participant Disk
          User->>CLI: spec2viz build --config vistas.yml --out arch.html --atoms-dir desk/atoms/
          CLI->>Deskops: build_deskops(config, out, base_dir, atoms_dir)
          Deskops->>VistasYML: yaml.safe_load(config_path)
          Deskops->>Template: read_text(template_path)
          Deskops->>AtomParser: parse_atoms(atoms_dir)
          AtomParser->>AtomsDir: glob('*.md')
          AtomParser->>AtomParser: regex split frontmatter + yaml.safe_load
          AtomParser->>Deskops: returns JSON string
          Deskops->>Deskops: build NAV + SECTIONS HTML
          Deskops->>Deskops: replace {{NAV}}, {{SECTIONS}}, {}
          Deskops->>Disk: out_path.write_text(html)
          Deskops->>CLI: returns
          CLI->>User: Rendered deskops architecture -#gt; arch.html

— Modelos de Estado —

Ciclo de Vida de una Spec

Máquina de estados de un archivo YAML: Raw → Dict → DiagramModel → Validated → IR → Output, con transiciones de error.

statetype:state
      stateDiagram-v2
          state "Raw YAML File" as raw_yaml
          state "Python Dict" as parsed_dict
          state "Pydantic DiagramModel" as validated_model
          state "Semantically Valid Model" as semantically_valid
          state "IR Dataclass" as compiled_ir
          state "Rendered Output" as rendered_output
          state "Error State" as error
          [*] --> raw_yaml
          raw_yaml --> parsed_dict : yaml.safe_load() [valid YAML syntax]
          raw_yaml --> error : yaml.safe_load() [malformed YAML]
          parsed_dict --> validated_model : TypeAdapter.validate_python() [schema matches]
          parsed_dict --> error : TypeAdapter.validate_python() [schema mismatch]
          validated_model --> semantically_valid : validate() [references resolve]
          validated_model --> error : validate() [broken refs]
          semantically_valid --> compiled_ir : compile_ir()
          compiled_ir --> rendered_output : render()
          compiled_ir --> error : render() [no renderer]

— Flujos de Actividad —

Manejo de Errores en Render

Flujo de decisiones del CLI render: para cada path, intenta load → validate → compile → render, con catch de excepciones por etapa.

activitytype:activity
      flowchart TD
          __start([Start])
          receive_paths["Receive SPEC paths from CLI args"]
          iterate_path{"For each path"}
          try_render["Call render_to_file(path, out, renderer)"]
          load_step{"load(path): YAML parse + Pydantic validate"}
          validate_step{"validate(diagram): check cross-references"}
          compile_step{"compile_ir(diagram): pattern-match compiler"}
          render_step{"render(ir, renderer): dispatch to backend"}
          write_output["Write result to disk"]
          echo_success["echo 'Rendered X -#gt; Y'"]
          catch_error["echo error to stderr + sys.exit(1)"]
          done["Exit"]
          __end([End])
          __start --> receive_paths
          receive_paths --> iterate_path
          iterate_path -->|"has_next"| try_render
          iterate_path -->|"empty"| __end
          try_render --> load_step
          load_step -->|"ok"| validate_step
          load_step -->|"ParseError"| catch_error
          validate_step -->|"ok"| compile_step
          validate_step -->|"ValidationError"| catch_error
          compile_step -->|"ok"| render_step
          compile_step -->|"CompileError"| catch_error
          render_step -->|"ok"| write_output
          render_step -->|"RenderError"| catch_error
          write_output --> echo_success
          echo_success --> iterate_path
          catch_error --> __end

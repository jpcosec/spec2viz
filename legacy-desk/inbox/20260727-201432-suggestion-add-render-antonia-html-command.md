# Add render-antonia-html command

Reference sample copied into inbox:
- `desk/inbox/antonIA_Arquitectura_V4.2_Vistas_UML.html`

Add a render-antonia-html workflow that takes one or more spec2viz YAML specs and emits a styled multi-section HTML page like antonIA_Arquitectura_V4.2_Vistas_UML.html. The command should bundle Mermaid output into a ready-to-open HTML artifact with section navigation, titles/descriptions per view, and support for component, deployment, sequence, state, class/data, and use-case sections so teams can publish boardroom-ready architecture docs without hand-assembling HTML around Mermaid blocks.
